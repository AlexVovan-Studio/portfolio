Privacy Policy for MyChatSense

Effective date: October 4, 2026

MyChatSense (“the App”) is an Android companion app that helps users read and reply to WhatsApp conversations in another language. This Privacy Policy explains what information the App accesses, how it is processed, when it leaves the device, and what choices users have.

1. Scope

MyChatSense is an independent application and is not affiliated with, endorsed by, or sponsored by WhatsApp LLC or Meta Platforms, Inc.

The App does not require a MyChatSense account. There is no MyChatSense registration, login, password, OAuth profile, advertising SDK, behavioral advertising, or third-party advertising/tracking SDK.

2. Accessibility Service

MyChatSense uses Android Accessibility Service only after the user is shown a prominent disclosure and gives consent.

The Accessibility Service is used to support the App’s core functionality, including:

  • reading the visible content of a WhatsApp or WhatsApp Business chat that the user opens or selects;
  • identifying the selected chat and visible message authors;
  • synchronizing visible messages into MyChatSense;
  • reading visible message text, replies, quotes, reactions, media labels/captions, document names or other visible message-related text;
  • reading WhatsApp-generated voice-message transcription when that transcription is visible on screen;
  • inserting a translated reply into the appropriate WhatsApp text field; and
  • returning the user to MyChatSense after the user manually sends the message.

MyChatSense does not automatically press the WhatsApp Send button. The final send action remains under the user’s control.

3. Information Stored Locally on the Device

For chats selected by the user, MyChatSense may store information locally on the Android device so the conversation can be displayed and translated. This may include:

  • message text;
  • translations;
  • chat names;
  • sender display names or phone numbers as shown by WhatsApp;
  • timestamps;
  • reactions;
  • replies and quotes;
  • message types;
  • visible media captions, labels, document names, location text, or similar visible metadata;
  • WhatsApp-generated voice-message transcription text;
  • per-chat language and display settings; and
  • the original text of the user’s own outgoing messages.

MyChatSense may also keep local technical diagnostics needed to troubleshoot the App. Diagnostic export is initiated manually by the user and is not automatically uploaded.

Android backup for MyChatSense is disabled. MyChatSense does not provide a cloud archive of the user’s full WhatsApp history.

Local data remains on the device until the user deletes the relevant chat in MyChatSense, clears the App’s data, or uninstalls the App.

4. Information Sent for Translation

When the user requests or triggers translation, the relevant text must leave the device.

The App sends a request over HTTPS to the MyChatSense backend. A translation request may include:

  • the text being translated;
  • source and target language information;
  • a limited amount of recent textual conversation context needed to improve translation quality;
  • sender information needed to understand who said what; and
  • limited message-related metadata needed for contextual translation.

The current translation logic may use up to approximately eight previous textual messages as context.

Sender information may initially contain a WhatsApp display name or, for an unsaved contact, a phone number as shown by WhatsApp. Before conversation context is sent onward to the AI translation provider, the MyChatSense backend replaces participant identifiers with neutral labels such as S1, S2, and similar pseudonymous identifiers.

5. AI Translation Provider

MyChatSense uses the OpenAI API as an AI service provider for translation.

The OpenAI API key is stored on the MyChatSense backend and is not embedded in the Android application.

Requests are configured with application-state storage disabled (store: false). OpenAI states that API inputs and outputs are not used to train its models by default unless the API customer explicitly opts in to data sharing.

OpenAI may retain API inputs and outputs in abuse-monitoring systems for a limited period, generally up to 30 days, unless a different retention arrangement applies or longer retention is required by law.

For more information, users may review OpenAI’s current business/API data privacy documentation.

6. Backend Processing and Operational Data

The MyChatSense backend is used to relay and protect translation requests. It includes technical safeguards such as rate limits, request-size limits, concurrency limits, timeouts, and usage controls.

MyChatSense does not use the backend as a cloud message-history service.

A persistent operational usage ledger may store a daily request count for abuse and cost protection. This counter does not contain the text of WhatsApp conversations.

Technical infrastructure may also process ordinary network and operational metadata necessary to provide, secure, and troubleshoot the service.

7. Photos, Videos, Documents, Voice Messages, and Dictation

MyChatSense does not upload the underlying WhatsApp binary media file merely because a selected chat contains a photo, video, PDF, or voice message.

For these message types, the App may use only text that is visible in the WhatsApp interface, such as:

  • a caption;
  • a document name;
  • a visible media label;
  • visible location/address text; or
  • WhatsApp-generated voice-message transcription.

For WhatsApp voice messages, MyChatSense reads the visible transcription text when available; it does not send the raw WhatsApp voice-message audio to the MyChatSense translation backend.

If the user chooses voice dictation for a reply, speech recognition is provided through Android/system speech-recognition functionality. MyChatSense receives the recognized text for translation. Processing performed by the device’s speech-recognition provider is subject to that provider’s own privacy practices.

8. Service Providers

To provide the translation service, MyChatSense relies on service providers that process data on behalf of the App, including:

  • hosting/infrastructure used by the MyChatSense backend; and
  • OpenAI API for AI-assisted translation.

These providers receive only the information needed to perform the relevant service.

MyChatSense does not sell personal data and does not use WhatsApp conversation content for advertising.

9. Security

MyChatSense uses HTTPS for communication with its backend and keeps the OpenAI API credential on the server rather than inside the Android app.

The service also uses technical controls intended to reduce abuse and unauthorized or excessive use. No method of electronic transmission or storage can be guaranteed to be completely secure.

10. User Choices and Deletion

Users control which WhatsApp chats are added to MyChatSense.

Users can remove locally stored MyChatSense data by:

  • deleting a chat from MyChatSense;
  • clearing MyChatSense application data in Android settings; or
  • uninstalling MyChatSense.

Because MyChatSense does not require a user account, there is no MyChatSense account profile to delete.

For privacy questions or requests concerning the service, users can contact the developer using the email address below.

11. Children

MyChatSense is not directed to children. The intended audience of the App is adults aged 18 and over.

12. Changes to This Privacy Policy

This Privacy Policy may be updated when the App’s functionality, data processing, service providers, or legal requirements change. The effective date at the top of this page will be updated when a new version is published.
