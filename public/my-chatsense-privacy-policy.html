Privacy Policy for MyChatSense

Effective date: September 29, 2026

MyChatSense is developed by AlexVovan Studio.

This Privacy Policy explains how MyChatSense accesses, processes, stores, and transfers information when you use the application.

MyChatSense is a companion application designed to help users translate WhatsApp conversations. MyChatSense does not operate its own messaging network and does not send WhatsApp messages without the user's confirmation.

1. Accessibility Service

MyChatSense uses the Android Accessibility Service as part of its core functionality.

The Accessibility Service is used with WhatsApp and WhatsApp Business to allow MyChatSense to:

  • read visible content from conversations selected by the user;
  • identify visible message text, message authors, timestamps, message types, reactions, quoted messages, and media-related labels;
  • obtain visible voice-message transcription text;
  • synchronize selected conversations with MyChatSense;
  • prepare translated replies;
  • insert translated text into the WhatsApp message field;
  • return the user to MyChatSense after the user manually sends a message.

MyChatSense does not automatically press the final Send button in WhatsApp. The user reviews the prepared text and decides whether to send it.

Accessibility access can be disabled at any time through Android system settings.

2. Information stored locally on the device

MyChatSense stores information necessary to display and manage conversations that the user chooses to add to the application.

Depending on the content of those conversations, locally stored information may include:

  • chat names;
  • sender names or phone numbers displayed by WhatsApp;
  • message text;
  • timestamps;
  • quoted-message text;
  • reactions;
  • message-type information;
  • media captions and labels;
  • document names and metadata;
  • location or address text displayed in a message;
  • visible voice-message transcription text;
  • translations;
  • language and chat settings;
  • original text entered through MyChatSense for translated outgoing messages.

The underlying photo, video, document, or voice-message audio file is not uploaded to the MyChatSense translation service as part of the normal translation workflow.

MyChatSense does not maintain a cloud copy of the user's complete WhatsApp conversation history.

Android application backup is disabled for MyChatSense.

3. Information processed for translation

When the user requests a translation, MyChatSense sends the text that needs to be translated to the MyChatSense translation service over an encrypted HTTPS connection.

To improve translation quality and preserve conversational context, MyChatSense may also send a limited amount of recent text from the same selected conversation.

Translation requests may therefore contain:

  • the text to be translated;
  • source and target language information;
  • limited recent conversation context;
  • information necessary to distinguish speakers or messages;
  • message-related metadata required to provide the requested translation.

Personal information contained directly inside message text may therefore also be processed when that text is translated.

The information is processed for the purpose of providing the requested translation.

4. AI processing

MyChatSense currently uses the OpenAI API to provide AI-assisted translation functionality.

Data submitted through the OpenAI API is not used by OpenAI to train or improve its models by default unless the API customer explicitly opts in to data sharing.

OpenAI may retain API abuse-monitoring information, including some request or response content, for up to 30 days by default, unless longer retention is required by law or necessary to protect its services or third parties.

MyChatSense does not use conversation content for advertising, behavioral profiling, or marketing.

5. Hosting infrastructure

The MyChatSense translation backend is currently hosted using Railway infrastructure.

Hosting and infrastructure providers may process technical information necessary to provide and secure their services, such as network information, IP addresses, request timing, and operational logs.

The MyChatSense backend is not designed to create a permanent server-side archive of users' WhatsApp conversations.

6. Voice messages and speech input

MyChatSense does not normally upload the raw audio file of a WhatsApp voice message to the MyChatSense translation service.

When a WhatsApp voice-message transcription is made visible in WhatsApp, MyChatSense may read the resulting transcription text. If the user requests translation of that transcription, the text is processed in the same way as other message text.

When the user uses the microphone button in MyChatSense to dictate a reply, the application uses the speech-recognition service available on the Android device.

The speech-recognition provider configured on the device may process audio according to that provider's own privacy practices. MyChatSense receives the recognized text for use in the application.

7. Diagnostics

MyChatSense contains a diagnostic system intended to help troubleshoot synchronization, translation, and Accessibility Service issues.

Diagnostic information is stored locally on the device and is not automatically uploaded to MyChatSense servers.

General Accessibility diagnostics are designed to contain technical event information rather than arbitrary conversation text.

Some diagnostic information associated with selected chats may nevertheless include information required to investigate a specific synchronization or message-handling problem.

A diagnostic report is shared only if the user deliberately exports or shares it.

8. Data retention and deletion

Information stored locally by MyChatSense remains on the device until it is removed through the application, the application's storage is cleared, or MyChatSense is uninstalled.

Removing a conversation from MyChatSense removes the corresponding local conversation data managed by the application. It does not delete messages from WhatsApp.

Clearing MyChatSense application storage or uninstalling the application removes locally stored MyChatSense application data.

The MyChatSense backend is not designed to maintain a permanent database of translated conversation content.

Third-party infrastructure and AI providers may retain limited operational, security, or abuse-monitoring information according to their own retention policies.

9. Data sharing and service providers

MyChatSense does not sell users' personal data.

MyChatSense does not use chat content for advertising.

Information may be processed by third-party service providers only where necessary to provide requested application functionality. These providers currently include:

  • Railway, for backend hosting and infrastructure;
  • OpenAI, for AI-assisted translation processing;
  • the speech-recognition service configured on the user's Android device when speech input is used.

When the user chooses to send a translated message, MyChatSense inserts the prepared text into WhatsApp. The user then decides whether to send the message.

Once content is sent through WhatsApp, its processing is governed by WhatsApp and its own privacy practices.

10. Analytics, advertising, and tracking

MyChatSense does not currently include third-party advertising SDKs.

MyChatSense does not currently use behavioral advertising, cross-app tracking, or marketing profiling.

MyChatSense does not require users to create a MyChatSense account.

11. Security

MyChatSense is designed to minimize unnecessary transmission of user data outside the device.

Translation requests are transmitted using HTTPS.

Local application data is stored in the application's private Android storage.

Android application backup is disabled.

No electronic storage or network transmission method can be guaranteed to be completely secure, but reasonable technical measures are used to reduce unauthorized access and unnecessary exposure of user data.

12. International data processing

Service providers used by MyChatSense may process information in countries other than the country where the user is located, including the United States.

Such providers process information according to their respective contractual, security, and legal obligations.

13. User choices

Users control:

  • which WhatsApp conversations are added to MyChatSense;
  • when translations are requested;
  • whether Accessibility Service access remains enabled;
  • whether speech-input features are used;
  • whether diagnostic reports are exported or shared.

Users may disable Accessibility Service access through Android settings, remove conversations from MyChatSense, clear application storage, or uninstall the application.

14. Children's privacy

MyChatSense is not specifically designed or directed toward children.

MyChatSense does not knowingly operate a system for creating user profiles or accounts for children.

If the developer becomes aware that personal information has been processed in a manner inconsistent with applicable legal requirements, appropriate steps will be taken to address the issue.

15. Changes to this Privacy Policy

This Privacy Policy may be updated if MyChatSense functionality, service providers, data practices, or legal requirements change.

When material changes are made, the effective date shown at the top of this Privacy Policy will be updated.
